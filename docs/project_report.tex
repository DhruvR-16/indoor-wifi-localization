\subsection{Abstract}\label{abstract}

Indoor Wi-Fi fingerprinting estimates a device\textquotesingle s
location from the received signal strength (RSSI) pattern of nearby
access points. This project predicts building, floor, and
two-dimensional coordinates from UJIIndoorLoc. Phase 1 establishes a
classical machine-learning baseline using data-quality analysis,
fold-safe Wi-Fi representations, Random Forest and XGBoost
classification, and routed coordinate regression. The cleaned training
set contains 19,300 scans after duplicate removal. Under five
USERID-grouped outer folds, tuned Random Forest achieved 99.34\%
building accuracy, tuned XGBoost achieved 77.10\% floor accuracy, and
tuned per-building k-nearest neighbors (kNN) achieved 12.21 m mean
position error.

Phase 2 investigates robustness, RSSI representations, denoising
pretraining, multitask neural networks, statistical evaluation, and
architecture width/depth. The available M3 experiments evaluated five
model configurations over five user folds and three seeds (75 runs); M4
produced paired out-of-fold analysis and a learning curve; M5 evaluated
four additional architecture variants. The independent-task M3 model has
the lowest observed mean EvAAL-style score among completed valid arms
(19.29 m), but its paired interval versus the shared M3 model includes
zero. M2\textquotesingle s A8 hybrid is not complete,
M1\textquotesingle s initial A5/A6 sweep uses a temporary model and has
an inner-split limitation, and paired A9 uncertainty and final candidate
selection are pending. Consequently, the report presents Phase 2 as
current experimental progress rather than a completed final comparison.

The project is an offline research pipeline using saved CSV scans. It
does not currently scan live Wi-Fi, deploy a mobile application, or
connect to a live database.

\subsection{1. Problem statement and
objectives}\label{1-problem-statement-and-objectives}

Satellite navigation is often unavailable or inaccurate indoors. Wi-Fi
fingerprinting offers an alternative: record signal strengths at known
places, then learn how a new signal pattern corresponds to a building,
floor, or coordinate. The localization problem is hierarchical and
multi-output:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  Predict one of three buildings.
\item
  Predict one of five encoded floor labels (the benchmark contains 13
  building-floor combinations).
\item
  Predict projected horizontal coordinates and report errors in metres.
\end{enumerate}

The project objectives are to establish a reproducible Phase 1 baseline;
compare model and feature choices without leaking user information
across folds; explore deep and hybrid models in Phase 2; report
uncertainty, negative results, and limitations; and preserve a workflow
that can be rerun from the repository.

\subsection{2. Dataset and exploratory
analysis}\label{2-dataset-and-exploratory-analysis}

\subsubsection{2.1 Dataset contents}\label{21-dataset-contents}

The UJIIndoorLoc dataset contains 19,937 training scans and 1,111
official validation scans (21,048 total). Each row has 529 columns: 520
WAP signal readings, four targets (\texttt{BUILDINGID}, \texttt{FLOOR},
\texttt{LONGITUDE}, \texttt{LATITUDE}), and five collection metadata
fields (\texttt{SPACEID}, \texttt{RELATIVEPOSITION}, \texttt{USERID},
\texttt{PHONEID}, \texttt{TIMESTAMP}). The locations cover three
buildings and 13 building-floor combinations {[}1{]}.

\subsection{3. Evaluation design and
metrics}\label{3-evaluation-design-and-metrics}

\subsubsection{3.1 User-grouped
validation}\label{31-user-grouped-validation}

The cleaned training data is partitioned into five deterministic outer
\texttt{GroupKFold} folds grouped by \texttt{USERID}. All rows from one
user remain in one partition. Across the five folds, each cleaned scan
is a held-out scan exactly once. Grouping by person tests generalization
to unseen users and avoids the optimistic results that can arise when
scans from the same user\textquotesingle s route appear in both training
and validation.

All transformations that estimate parameters---including scaling, PCA,
variance selection, and coordinate target scaling---are fitted on the
training side of a fold and then applied unchanged to its held-out
users. Model settings and stopping times are selected within
outer-training users where the experiment uses nested selection.
Out-of-fold (OOF) means a scan\textquotesingle s prediction comes from a
model that did not train on that scan or its user.

\subsubsection{3.2 Metrics}\label{32-metrics}

\begin{itemize}
\tightlist
\item
  \textbf{Accuracy:} proportion of exact class predictions that are
  correct.
\item
  \textbf{Macro-F1:} F1 computed per class and averaged equally, so
  minority classes contribute more than in raw accuracy alone.
\item
  \textbf{Position error:} Euclidean distance between true and predicted
  coordinates after inverse scaling, in metres. Mean, median, and 95th
  percentile are reported to describe average, typical, and tail
  performance.
\item
  \textbf{EvAAL-style score:}
  \texttt{position\ error\ +\ 50\ m\ ×\ wrong-building\ indicator\ +\ 4\ m\ ×\ wrong-floor\ indicator}.
  Lower is better. It encodes that a wrong building is costlier than a
  wrong floor; it is a designed penalty score, not physical distance.
  Classification and unpenalized coordinate metrics are reported beside
  it.
\item
  \textbf{Calibration:} M4 reports floor expected calibration error
  (ECE), Brier score, and negative log-likelihood (NLL). ECE depends on
  binning and should not be used alone.
\item
  \textbf{Uncertainty:} M4\textquotesingle s paired percentile bootstrap
  resamples USERID clusters so multiple scans from one person are not
  treated as independent. Current multi-model findings remain
  exploratory because comparisons are unadjusted for multiple testing.
\end{itemize}

\subsubsection{3.3 Official validation
file}\label{33-official-validation-file}

The official 1,111-row file was evaluated earlier with fixed Phase 1
model settings. It is not a fresh final test set for the tuned Phase 1
or Phase 2 comparisons and was not used for Phase 2 selection. The
primary evidence in this report is grouped cross-validation on the
training scans. Any future official-file result must disclose this
earlier use.

\subsection{4. Phase 1: classical machine-learning
baseline}\label{4-phase-1-classical-machine-learning-baseline}

\subsubsection{4.1 Signal features}\label{41-signal-features}

The 55 constant WAPs are dropped, leaving 465 signal channels. Phase 1
maps a missing WAP to \texttt{−110\ dBm}, uses an explicit absence
indicator, and compares three signal views:

\begin{itemize}
\tightlist
\item
  Linear-positive: \texttt{x\ =\ (r\ +\ 110)\ /\ 110}.
\item
  Exponential: \texttt{x\ =\ exp(r\ /\ 24)} for observed RSSI
  \texttt{r}.
\item
  Power view: normalized positive signal raised to \texttt{e}.
\end{itemize}

Missing values map to zero in each view. Eleven per-scan summaries
describe detected AP count, strongest signal and its AP, average/spread
of observed signals, and top AP information. Thus the main classifier
representation contains 465 transformed readings + 465 missingness
indicators + 11 summaries = 941 inputs. PCA and variance filtering are
performed inside the training fold; the transform is then reused on
held-out users. The representation choices are motivated by Wi-Fi
fingerprint similarity research {[}2, 3{]}.

\subsubsection{4.2 Building and floor
classification}\label{42-building-and-floor-classification}

Random Forest and XGBoost classifiers model nonlinear interactions among
signal features. Tuning uses nested USERID-grouped splits. Accuracy is
interpreted alongside macro-F1 and confusion matrices because class
support is imbalanced, particularly for floor 4.

\subsubsection{5.2 Shared data contract and evaluation
protocol}\label{52-shared-data-contract-and-evaluation-protocol}

Phase 2 retains the complete 520 ordered WAP columns. Phase 1 removes 55
WAPs constant in the complete training partition; Phase 2 retains 520
positions so each fold and model has a stable input dimension even when
an AP happens to be constant in one subset. For detected RSSI
\texttt{r}, linear-positive encoding is
\texttt{(clip(r,\ -110,\ 0)\ +\ 110)\ /\ 110}. The source sentinel
\texttt{+100} maps to exactly zero, while detected readings map to a
positive value. In a missingness-mask arm, a 520-bit detection vector is
concatenated with the signal vector for 1,040 inputs. Transform/scaler
parameters and coordinate scaling are fitted using training users only.

The five outer folds reuse \texttt{GroupKFold} grouped by
\texttt{USERID}; seeds are 42, 1337, and 2024. For each fold, the outer
validation users are not used for fitting, augmentation, hyperparameter
selection, or stopping selection. Where the method uses nested
selection, a grouped inner split selects epoch or fixed loss weights.
The selected model is then refit on the full outer-training users, and
the held-out outer users are scored. OOF predictions record one held-out
prediction for every cleaned scan per complete arm and seed.
M2\textquotesingle s \texttt{verify\_m2\_phase2.py} checks this protocol
and the saved predictions; its current audit reports 47 checks passed
and zero failed. Phase 2 avoids the official 1,111-row file because it
was evaluated previously for the fixed Phase 1 baseline.

The primary Phase 2 metric is the EvAAL-style score from Section 3.2.
Because it adds a 50 m building penalty and a 4 m floor penalty, it
weights building correctness more heavily. We therefore report
building/floor accuracy and unpenalized Euclidean position error
alongside it. Across-run mean +/- standard deviation, pooled scan OOF
results, and paired group-level confidence intervals answer different
questions and are labeled separately below.

\subsubsection{5.3 M1 --- input contract, robustness, and regularization
(A5/A6)}\label{53-m1--input-contract-robustness-and-regularization-a5a6}

\texttt{src/data/phase2.py} and
\path{src/training/phase2_trainer.py}.

nine A5/A6 alternatives. The saved reference uses dropout 0.2, batch
normalization enabled, no weight decay, Adam with learning rate
\texttt{1e-3}, batch size 64, maximum 20 epochs, patience 6, and equal

\textbf{Important M1 limitations:} an audit found that the trainer
imports \texttt{src/models/stub\_multitask.py}. Its 150 runs use a
\texttt{520\ →\ 256\ →\ 128} shared trunk and a linear coordinate head,
whereas M3\textquotesingle s final model has a
\texttt{520\ →\ 512\ →\ 256\ →\ 128} trunk and \texttt{128\ →\ 64\ →\ 2}
coordinate head. Also, plain inner \texttt{GroupKFold} can leave
building 0 out of inner training on outer folds 0 and 1 because only
users 1 and 11 represent that building. The outer users remain held out,
but the epoch selection for those two folds is not label-coverage-safe.
Thus the initial sweep may be reported as a completed experiment on the
temporary architecture, but its conclusions are provisional for
M3\textquotesingle s final model. An architecture-matched rerun with
label-covered inner validation remains required.

M2 compares the impact of signal geometry with a matched
\texttt{520\ →\ 256\ →\ 128} reference network. For an observed reading
\texttt{r}, let \texttt{P\ =\ clip(r,\ -110,\ 0)\ +\ 110} and
\texttt{R=110}. The views are linear-positive \texttt{P/R}, exponential
\texttt{exp(P/alpha)/exp(R/alpha)} with \texttt{alpha=24\ dB}, and power
\texttt{(P/R)\^{}beta} with \texttt{beta=e}. Each view is tested with
and without a 520-element binary AP detection mask, producing six arms.
A4 has 6 × 5 × 3 = 90 fold/seed runs. The transforms are deterministic
per reading and require no statistics to be fitted on validation data;
their motivation is Wi-Fi fingerprint similarity research {[}2{]}.

The result is an interaction: missingness masks help the nonlinear views
because they distinguish ``weak but detected'' from ``not detected.''
Without a mask, the powed transform pushes some weak observations near
zero, colliding with the missing code; the exponential transform
compresses much of the signal dynamic range. The best EvAAL arm is not
best on every output: masked arms improve building accuracy but reduce
floor accuracy. Since the metric penalizes a wrong building by 50 m but
a wrong floor by 4 m, its apparent gain partly reflects that weighting.
In the paired five-fold comparison to unmasked linear, powed-mask has
mean fold difference -2.91 +/- 2.28 m, p=0.046, wins all five folds and
12/15 matched runs. Other mask comparisons are inconclusive. This
p-value is unadjusted across several arms and should be called
exploratory, not definitive proof of universal superiority.

\paragraph{A7: denoising autoencoder
pretraining}\label{a7-denoising-autoencoder-pretraining}

The DAE encoder is \texttt{520\ →\ 256\ →\ 128}, with batch
normalization, ReLU, and dropout 0.2; the decoder mirrors the hidden
layers and ends with sigmoid because the input view is in
\texttt{{[}0,1{]}}. One DAE is trained for each outer fold and seed on
outer-training users only. Its input receives 4 dBm Gaussian noise and
10\% AP dropout on observed values; its target is the corresponding
clean vector, and missingness is preserved. Around 96\% of entries are
missing, so the code scores reconstruction on observed and missing
entries separately and uses
\texttt{1.0\ ×\ observed\_MSE\ +\ 0.1\ ×\ missing\_MSE}. This reduces
the risk that the model appears successful simply by reconstructing
zeros. The encoder is transferred to the downstream MLP only when layer
shapes match; mismatches raise an error.

\paragraph{A8: hybrid status and why current values are
excluded}\label{a8-hybrid-status-and-why-current-values-are-excluded}

The intended A8 goal is to test whether a fold-specific, learned
embedding can improve on the MLP and Phase 1 coordinate approach. Its
planned candidates are the MLP coordinate head, embedding +
distance-weighted kNN, the Phase 1 hierarchical classifier/regressor
route under the same folds, and a stacking blend. The M3 encoder must be
trained without outer test users; downstream regressors fit only
outer-training embeddings; test routing uses predicted building/floor.
Stacking requires leakage-safe out-of-fold base predictions within outer
training. Oracle labels can appear only in a diagnostic column and
cannot be headline predictions.

The current A8 runner imports the temporary stub rather than
\texttt{src/models/dl/multitask.py}. It implements only the MLP head and
embedding+kNN of the required four; an embedding+XGBoost arm and oracle
diagnostic do not replace the missing matched Phase 1 hierarchy and
stacking methods. Existing A8 runs are tagged \texttt{blocked\_on\_m3}
and are excluded. \textbf{A8 is incomplete and no current A8 score
should be claimed as a valid hybrid result.}

\subsubsection{5.5 M3 --- multitask model architecture and ablations
(A1-A3)}\label{55-m3--multitask-model-architecture-and-ablations-a1-a3}

\paragraph{Network and objective}\label{network-and-objective}

M3\textquotesingle s default shared network accepts 520 RSSI values and
uses a \texttt{520\ →\ 512\ →\ 256\ →\ 128} trunk. The first two layers
use linear transformation, batch normalization, ReLU, and dropout 0.3;
the final trunk layer uses linear + ReLU. Its 128-value representation
feeds three task heads: building \texttt{128\ →\ 3}, floor
\texttt{128\ →\ 5}, and coordinate \texttt{128\ →\ 64\ →\ 2}. The
coordinate output is standardized per training fold, then
inverse-transformed to metres for scoring. The model has an
\texttt{encode()} method to expose the learned 128-D representation for
a future valid hybrid.

The shared equal-weight objective is
\texttt{L\ =\ CE\_building\ +\ CE\_floor\ +\ Huber\_coordinates}.
Cross-entropy trains class probabilities; Huber is quadratic for small
coordinate residuals and linear for large residuals, reducing
sensitivity to large outliers compared with squared error. A1 compares
the shared trunk with three independent task trunks. A2 chooses among
fixed loss weights \texttt{(0.5,0.5,2)}, \texttt{(1,1,1)},
\texttt{(1,1,2)} using inner validation only and compares this with
learned uncertainty weights \texttt{sum\_t{[}exp(-s\_t)L\_t+s\_t{]}}. A3
uses three building-conditioned floor heads and combines their logits
using predicted building probabilities, so it does not use true building
labels at inference.

The M3 trainer uses AdamW (learning rate \texttt{1e-3}, weight decay
\texttt{1e-4}), batch size 256, up to 200 epochs, patience 20, and
ReduceLROnPlateau scheduling (factor 0.5 after five non-improving
validation epochs). The inner split is grouped by user and checked to
cover building labels. The 75-run sweep is five unique configurations ×
five outer folds × three seeds; identical shared controls are run only
once.

\subsubsection{5.6 M4 --- paired statistics, calibration, learning

analysis}\label{56-m4--paired-statistics-calibration-learning-curve-and-error-analysis}

M4 checks that predictions align by source row, user, phone, target
labels, fold, and seed before comparing. It restores original coordinate
truth from the cleaned dataset using \texttt{source\_row}, because the
M3 prediction export stores coordinates as float32 and can round
northings by roughly half a metre. Metrics are computed on the same
19,300 scans, five outer folds, and three seeds whenever an arm is
eligible.

For uncertainty, M4 averages each user\textquotesingle s score over
scans and seeds, samples the 18 USERID groups 2,000 times with
replacement, and forms paired percentile 95\% intervals. Both models in
a comparison use the same sampled users. This respects within-user scan
dependence better than resampling thousands of scans independently. M4
also reports the exact McNemar test for seed-42 floor correctness at
scan level; this is a secondary diagnostic because repeated scans per
user violate the test\textquotesingle s independence assumption. No
multiple-comparison correction is applied, so the analyses are
exploratory.

\subsection{6. Cross-phase comparison and
interpretation}\label{6-cross-phase-comparison-and-interpretation}

The available reports show that Phase 1\textquotesingle s tuned
per-building kNN has a lower mean position error (12.21 m) than the
current Phase 2 neural models (for example, M3 independent around 15.91
m). These numbers arise from different model families and report
aggregation protocols, so comparisons require care. Phase 2 should not
be described as having improved over Phase 1 on coordinate accuracy
based on the current evidence. Potential advantages of Phase 2 include
joint outputs, learned embeddings, and extensible neural ablations; the
valid A8 hybrid that was intended to test a learned-space local
estimator remains incomplete.

There is also an architecture mismatch in member comparisons: M1 and M2
A4/A7 use a smaller \texttt{520\ →\ 256\ →\ 128} interface model,
whereas M3 uses \texttt{520\ →\ 512\ →\ 256\ →\ 128} with a nonlinear
coordinate head. A5/A6 and A4/A7 comparisons are controlled within their
own experiment families, but cross-member rows do not isolate
architecture causally.

\subsection{8. Limitations and future
work}\label{8-limitations-and-future-work}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{Complete A8:} connect M2 to M3\textquotesingle s actual
  fold-specific encoder; implement all planned hybrid candidates,
  including the matched Phase 1 hierarchical route and leakage-safe
  stacking; rerun and compare on the same USERID folds and seeds.
\item
  \textbf{Correct and repeat M1:} run A5/A6 using the final M3 model
  factory and an inner grouped split that covers all validation labels;
  keep initial artifacts for transparent comparison.
\item
  \textbf{Complete M4/M5 inference:} extend paired USERID-cluster
  uncertainty to A9, agree on the primary final selection metric and
  candidate, and update the report with the result.
\item
  \textbf{Finalize integration and demo:} regenerate tables/figures
  after valid A8 and M1 results; provide a reproducible saved-row
  prediction demonstration and document its input/output.
\item
  \textbf{Plan live localization separately:} live operation needs
  target-building fingerprint collection, BSSID-to-model-slot mapping,
  platform-specific scanning, matching preprocessing, packaged
  inference, and validation on phones/environment not represented by the
  public data. The current UJIIndoorLoc CSV does not itself supply an
  arbitrary current-device-to-WAP-slot mapping.
\item
  \textbf{Limit generalization claims:} building 0 has only two users,
  the outer design has five folds, and class/phone/environment shifts
  can affect performance. A result on this benchmark is not proof of
  accuracy in a new building.
\end{enumerate}

\subsection{9. Conclusion}\label{9-conclusion}

Phase 1 delivers a reproducible and interpretable classical baseline:
tuned tree ensembles classify building/floor, and a per-building kNN
route gives the strongest reported coordinate result. Phase 2 has
completed substantial controlled experiments in robustness, signal
representations, pretraining, multitask architecture, statistical
diagnostics, learning curves, and width/depth. The best observed Phase 2
mean is the 512×4 A9 result, but its paired uncertainty is pending; M3
independent is the best observed completed neural arm, with no
statistically reliable EvAAL gain established versus its shared control.
A8 and an architecture-matched M1 rerun remain important outstanding
work. Therefore, the project has meaningful Phase 2 results, but the
final Phase 2 model comparison and complete project conclusion should be
finalized only after the listed work is done.
