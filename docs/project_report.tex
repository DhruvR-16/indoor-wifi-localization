\section{Abstract}\label{abstract}

Wi-Fi fingerprint localization predicts indoor position from the signal
strengths of nearby access points. This project uses UJIIndoorLoc to
estimate building, floor, and horizontal coordinates. After cleaning
19,937 source training scans to 19,300 unique records, Phase 1 develops
fold-safe signal features, tree-ensemble classifiers, and a routed
coordinate regressor. Under five user-grouped folds, tuned Random Forest
reaches 99.34\% building accuracy, tuned XGBoost reaches 77.10\% floor
accuracy, and a predicted-building k-nearest-neighbor route achieves
12.21 m mean coordinate error. Phase 2 evaluates neural signal
representations, pretraining, task architectures, robustness, and model
capacity using the same user-held-out principle and three random seeds.
Independent task networks yield a pooled combined localization score of
19.29 m; a four-layer, 512-unit architecture obtains the lowest
descriptive fold/seed mean score in the capacity sweep at 16.68 ± 6.01
m. The neural experiments reveal model-design trade-offs but do not
establish a coordinate-accuracy improvement over the Phase 1 route. The
project uses recorded scans and reports no live positioning result.

\section{1. Problem statement and
objectives}\label{problem-statement-and-objectives}

Satellite navigation is often unavailable or inaccurate indoors. Wi-Fi
fingerprinting offers an alternative: record signal strengths at known
places, then learn how a new signal pattern corresponds to a building,
floor, or coordinate. The localization problem is hierarchical and
multi-output:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  Predict one of three buildings.
\item
  Predict one of five encoded floor labels (the benchmark contains 13
  building-floor combinations).
\item
  Predict projected horizontal coordinates and report errors in metres.
\end{enumerate}

The project objectives are to establish a reproducible Phase 1 baseline;
compare model and feature choices without leaking user information
across folds; investigate deep-learning alternatives in Phase 2; report
uncertainty, negative results, and limitations; and preserve a workflow
that can be rerun from the repository.

\section{2. Dataset and exploratory
analysis}\label{dataset-and-exploratory-analysis}

\subsection{2.1 Dataset contents}\label{dataset-contents}

The UJIIndoorLoc dataset contains 19,937 training scans and 1,111
official validation scans (21,048 total). Each row has 529 columns: 520
WAP signal readings, four targets (\texttt{BUILDINGID}, \texttt{FLOOR},
\texttt{LONGITUDE}, \texttt{LATITUDE}), and five collection metadata
fields (\texttt{SPACEID}, \texttt{RELATIVEPOSITION}, \texttt{USERID},
\texttt{PHONEID}, \texttt{TIMESTAMP}). The locations cover three
buildings and 13 building-floor combinations {[}1{]}.

building/floor/user/phone, coordinate maps, class support, and

performed on signal data and relevant labels/metadata, not as an

\section{3. Evaluation design and
metrics}\label{evaluation-design-and-metrics}

\subsection{3.1 User-grouped validation}\label{user-grouped-validation}

The cleaned training data is partitioned into five deterministic outer
\texttt{GroupKFold} folds grouped by \texttt{USERID}. All rows from one
user remain in one partition. Across the five folds, each cleaned scan
is a held-out scan exactly once. Grouping by person tests generalization
to unseen users and avoids the optimistic results that can arise when
scans from the same user's route appear in both training and validation.

All transformations that estimate parameters---including scaling, PCA,
variance selection, and coordinate target scaling---are fitted on the
training side of a fold and then applied unchanged to its held-out
users. Model settings and stopping times are selected within
outer-training users where the experiment uses nested selection.
Out-of-fold (OOF) means a scan's prediction comes from a model that did
not train on that scan or its user.

\subsection{3.2 Metrics}\label{metrics}

\begin{itemize}
\tightlist
\item
  \textbf{Accuracy:} proportion of exact class predictions that are
  correct.
\item
  \textbf{Macro-F1:} F1 computed per class and averaged equally, so
  minority classes contribute more than in raw accuracy alone.
\item
  \textbf{Position error:} Euclidean distance between true and predicted
  coordinates after inverse scaling, in metres. Mean, median, and 95th
  percentile are reported to describe average, typical, and tail
  performance.
\item
  \textbf{EvAAL-style score:}
  \texttt{position\ error\ +\ 50\ m\ ×\ wrong-building\ indicator\ +\ 4\ m\ ×\ wrong-floor\ indicator}.
  Lower is better. It encodes that a wrong building is costlier than a
  wrong floor; it is a designed penalty score, not physical distance.
  Classification and unpenalized coordinate metrics are reported beside
  it.
\item
  \textbf{Calibration:} The neural evaluation reports floor expected
  calibration error (ECE), Brier score, and negative log-likelihood
  (NLL). ECE depends on binning and should not be used alone.
\item
  \textbf{Uncertainty:} The paired percentile bootstrap resamples USERID
  clusters so multiple scans from one person are not treated as
  independent. Current multi-model findings remain exploratory because
  comparisons are unadjusted for multiple testing.
\end{itemize}

\subsection{3.3 Official validation
file}\label{official-validation-file}

The official 1,111-row file was evaluated earlier with fixed Phase 1
model settings. It is not a fresh final test set for the tuned Phase 1
or Phase 2 comparisons and was not used for Phase 2 selection. The
primary evidence in this report is grouped cross-validation on the
training scans. This earlier use limits the interpretation of any
subsequent official-file evaluation.

\section{4. Classical machine-learning
baseline}\label{classical-machine-learning-baseline}

\subsection{4.1 Signal features}\label{signal-features}

The 55 constant WAPs are dropped, leaving 465 signal channels. Phase 1
maps a missing WAP to \texttt{−110\ dBm}, uses an explicit absence
indicator, and compares three signal views:

\begin{itemize}
\tightlist
\item
  Linear-positive: \texttt{x\ =\ (r\ +\ 110)\ /\ 110}.
\item
  Exponential: \texttt{x\ =\ exp(r\ /\ 24)} for observed RSSI
  \texttt{r}.
\item
  Power view: normalized positive signal raised to \texttt{e}.
\end{itemize}

Missing values map to zero in each view. Eleven per-scan summaries
describe detected AP count, strongest signal and its AP, average/spread
of observed signals, and top AP information. Thus the main classifier
representation contains 465 transformed readings + 465 missingness
indicators + 11 summaries = 941 inputs. PCA and variance filtering are
performed inside the training fold; the transform is then reused on
held-out users. The representation choices are motivated by Wi-Fi
fingerprint similarity research {[}2, 3{]}.

\subsection{4.2 Building and floor
classification}\label{building-and-floor-classification}

Random Forest and XGBoost classifiers model nonlinear interactions among
signal features. Tuning uses nested USERID-grouped splits. Accuracy is
interpreted alongside macro-F1 and confusion matrices because class
support is imbalanced, particularly for floor 4.

The reference Random Forest uses 300 trees, square-root feature sampling,
and class-balanced subsampling. The reference XGBoost classifier uses 250
trees of maximum depth 6, learning rate 0.05, and 0.8 row and column
subsampling. Inner grouped validation selects task-specific settings
within each outer training fold, so the tuned result is a nested
evaluation rather than the score of one setting chosen on all users.

\section{5. Neural methods and experimental
design}\label{neural-methods-and-experimental-design}

\subsection{5.1 Signal representation and
missingness}\label{signal-representation-and-missingness}

The linear-positive view maps an observed RSSI \texttt{r} to
\texttt{(clip(r,-110,0)+110)/110}. Additional views use an exponential
map with scale 24 dBm and a power map with exponent \texttt{e}. Each is
evaluated with and without a 520-element binary detection mask. The mask
distinguishes a weak observed signal from an undetected access point.
The six representation configurations share the same 520 → 256 → 128
reference network and were assessed over five folds and three seeds,
giving 90 fold/seed runs.

\subsection{5.2 Denoising pretraining}\label{denoising-pretraining}

A denoising autoencoder has a 520 → 256 → 128 encoder and a mirrored
decoder with sigmoid output for the normalized signal view. On
outer-training users only, observed readings receive Gaussian noise with
4 dBm standard deviation and 10\% access-point dropout. The training
target is the uncorrupted fingerprint. Because roughly 96\% of entries
are absent, reconstruction uses
\texttt{observed\_MSE\ +\ 0.1\ ×\ missing\_MSE} rather than allowing
zero reconstruction to dominate. The trained encoder initializes the
matching supervised reference network; a random initialization provides
the controlled comparison. Each arm has 15 fold/seed runs.

\subsection{5.3 Task architecture and
objective}\label{task-architecture-and-objective}

The principal shared network takes 520 inputs through hidden widths 512,
256, and 128. The first two blocks apply a linear layer, batch
normalization, ReLU, and dropout 0.3; the last uses a linear layer and
ReLU. Its 128-dimensional representation feeds building (128 → 3), floor
(128 → 5), and coordinate (128 → 64 → 2) heads. The default objective is
building cross-entropy + floor cross-entropy + coordinate Huber loss.
Huber loss limits the influence of large coordinate errors relative to
squared loss.

Controlled alternatives use a separate trunk for each task; choose fixed
loss weights from \texttt{(0.5,0.5,2)}, \texttt{(1,1,1)}, and
\texttt{(1,1,2)} within grouped inner validation; learn task uncertainty
weights; or condition floor logits on predicted building probabilities.
The last design uses predicted, never true, building labels during
inference. Training uses AdamW (learning rate \texttt{1e-3}, weight
decay \texttt{1e-4}), batch size 256, at most 200 epochs, patience 20,
and a learning-rate reduction by 0.5 after five non-improving validation
epochs. Grouped inner splits are checked for building-label coverage.
The five distinct task configurations yield 75 fold/seed runs. In
contrast to the Phase 1 feature table, these networks retain all 520
ordered WAP positions.

\subsection{5.4 Regularization, robustness, and
capacity}\label{regularization-robustness-and-capacity}

A separate 520 → 256 → 128 reference network tests dropout, weight
decay, batch normalization, Gaussian signal noise, and access-point
dropout. The ten configurations produce 150 fold/seed runs. The
reference setting uses dropout 0.2, batch normalization, no weight
decay, Adam at \texttt{1e-3}, batch size 64, and up to 20 epochs with
patience 6. Signal perturbations are applied only to training inputs;
absent WAPs remain absent.

A controlled architecture sweep changes one factor at a time around the
independent-task network with width 512 and depth 3. Depth 2 and 4 are
tested at width 512; width 256 and 1024 are tested at depth 3. The four
new variants contribute 60 fold/seed runs, and the reference reuses 15
existing runs.

\section{7. Cross-phase interpretation and study
limitations}\label{cross-phase-interpretation-and-study-limitations}

The strongest reported Phase 1 coordinate result is 12.21 m mean error
for tuned per-building k-nearest neighbors using predicted building
routing. The best architecture in the Phase 2 width/depth sweep has a
13.99 m mean run-level position error. These estimates come from related
user-grouped experiments but from different model families and
aggregation summaries. The measured Phase 2 neural results therefore do
not establish a coordinate-accuracy improvement over the classical
baseline. The neural study instead supplies controlled evidence about
representation, task design, and capacity.

The robustness sweep uses a smaller reference network than the principal
task-design and capacity experiments. Its comparisons are valid within
that sweep, but the changes cannot be isolated from architecture when
compared with the larger models. Two outer folds in that sweep have
limited building-label coverage in the inner stopping split; this
affects the reliability of the selected stopping epoch, although their
outer assessment users remain held out. The benchmark has only 18 user
groups after cleaning, so uncertainty is better estimated by
user-cluster resampling than by treating individual scans as
independent. The bootstrap intervals are unadjusted across many
comparisons. The official validation file was previously used for a
Phase 1 baseline and is not treated as fresh independent confirmation.
Finally, the data consist of recorded fingerprints from the benchmark
buildings; the project does not establish performance on a new building,
phone fleet, or live scan.

\section{9. Conclusion}\label{conclusion}

This project establishes a reproducible offline Wi-Fi fingerprint
localization pipeline across classical and neural methods. Phase 1
achieves 99.34\% pooled building accuracy with tuned Random Forest,
77.10\% floor accuracy with tuned XGBoost, and 12.21 m mean coordinate
error with predicted-building routed k-nearest neighbors. Phase 2
evaluates representation, pretraining, task sharing, regularization,
learning curves, and network capacity on user-grouped folds. Independent
task networks give the lowest pooled combined score among the principal
task-design variants (19.29 m), while a 512-unit, four-layer capacity
variant has the lowest descriptive fold/seed score in its sweep (16.68 ±
6.01 m). Paired intervals do not establish a reliable combined-score
gain for independent versus shared task learning; the Phase 1 route
remains the stronger reported coordinate estimator. The measured outcome
is a technically documented comparison of model choices, with clear
limits on cross-family and live-deployment claims.
